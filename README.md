# TraeIDE-Switcher

Trae / Trae CN 多账号切换器 —— 面向 Windows 的桌面工具，用于在本机集中管理多个 Trae 账号，并在账号间快速切换、按额度自动换号，同时保持各账号独立的设备身份。

- 开源仓库：<https://github.com/WanJiu-LF/TraeIDE-Switcher>
- 更新来源：GitHub 官方发布页
- 运行平台：Windows x64
- 开源许可：MIT License

## 功能特性

### 账号管理
- 同时管理 Trae 国际版与 Trae CN 国内版账号，当前生效状态按版本独立判定，互不串号。
- 多种入池方式：粘贴 Token、读取本机已登录账号、登录窗口采集。粘贴时只认 `iCubeAuthInfo://icube.cloudide` 的值，也可以直接贴整个 `storage.json` 或其中那一行；误贴 `usertag`、`icube-dc` 会给出提示。
- 账号置顶、编辑、删除、批量操作，卡片展示账号名、套餐、剩余额度与到期时间。
- 账号库自动备份与一键恢复：每次改动前保留上一版，支持导出/导入加密备份。

### 无感换号
- IDE 运行中直接切换账号，无需重启、无需重新登录。
- 切换过程同步账号对应的设备身份，避免触发服务端设备绑定限制。
- 切换前对目标账号 Token 预检刷新，并对切换后的强制登出回调做短时拦截保护。
- 支持「无感换号支持」文件补丁 + 切换助手组合，补丁不可用时自动转为备用通道。

### 会话迁移
- 换号时自动把其他账号在同一工作区的会话改挂到当前账号，切号后立即可读。
- 「会话迁移」页可勾选指定会话迁移，也可一键全部迁移；按原工作区对位，找不到对应项目时留在原账号。
- 迁移前自动整库备份对话库，可在同页回滚；不会改动消息内容。

### 自动换号
- 账号额度耗尽时自动切换到下一个可用账号，可设置触发阈值。
- 换号策略支持「按顺序轮换」与「剩余额度优先」。
- 换号范围支持「全部账号」与「仅置顶账号」。
- 单个账号可在编辑时单独设置阈值；仅在 IDE 运行时生效，不替用户意外拉起进程。

### 积分与诊断
- 并发查询全部账号剩余额度，记录消耗趋势并绘制趋势曲线。
- 自动读取账号资产：积分、会话用量、活动奖励、订阅能力、设备身份与账单记录。
- 会话级用量明细展示每个会话的轮次与 Token 消耗，随 IDE 状态自动刷新。
- 每日定时签到（Trae CN）与定时刷新额度，每个账号使用独立且稳定的签到设备标识。

### 运行与运维
- 运行检查页集中展示 IDE 安装、进程、无感换号通道、补丁加载等状态，后台定时轮询。
- 日志分级记录（系统、切换、额度、注入等来源），支持导出。
- 系统托盘常驻，关闭到托盘后后台继续自动换号；支持开机自启与系统通知。

## 工作原理

### 无感换号（推荐）
在 Trae 安装目录的渲染层入口与主进程入口注入「无感换号支持」补丁，并通过一个本地 shim 扩展与触发文件通信。换号时，换号器写入目标账号的凭据与设备资产，补丁在运行中的 Trae 内完成用户信息与设备身份的替换，无需重启 IDE。

推荐组合为「无感换号支持 + 切换助手」：先安装无感换号支持，再安装切换助手，重启 Trae 后即可无感换号。若无感换号支持文件未安装成功，将自动转为备用通道（需从本换号器启动 Trae）。安装时需以管理员身份运行本软件，并先关闭 Trae。

### 重启切换（备用通道）
IDE 未运行或补丁不可用时，执行完整切换：终止 Trae 进程 → 写入账号对应的凭据、TinyStorage 快照、ECDSA 密钥对、遥测信息与签到设备标识 → 重启 Trae。

### 设备身份随号
同一账号的设备身份（device_id、machineId、ECDSA 密钥）独立存储。切换后同步该身份，避免不同账号共用同一设备触发风控与设备绑定上限；历史入库账号若缺少设备资产，则保留本机现值，避免制造设备漂移。

### 数据保留
- machineId 始终保留本机原值，不随账号切换，避免设备漂移。
- 换号只改写账号登录态与设备身份，不删除任何会话。

## 环境要求与安装

- 系统：Windows 10 / 11 x64
- 运行环境：Microsoft Edge WebView2（Windows 11 及多数 Windows 10 已内置）
- 权限：使用无感换号支持文件时需要管理员身份运行本软件，并先关闭 Trae

安装：从本仓库的 [Releases 页面](https://github.com/WanJiu-LF/TraeIDE-Switcher/releases) 下载 `TraeIDE-Switcher_x.y.z_x64-setup.exe` 并安装。应用内「关于」页可检查更新。

## 使用流程

1. 启动换号器，在侧栏选择目标版本（Trae 或 Trae CN）。
2. 在「账号池」通过粘贴 Token、读取本机 Token 或登录窗口采集添加账号入池。
3. 在「设置 → 无感换号通道」以管理员身份安装无感换号支持与切换助手，关闭并重启 Trae。
4. 在「运行检查」确认无感换号通道与补丁加载正常。
5. 在「账号池」对目标账号点击切换：
   - IDE 运行时走无感换号通道；
   - IDE 未运行时执行重启切换。
6. 如需自动换号，在「设置」开启自动换号并配置策略、范围与阈值。

## 自动更新链路

- 应用内：在「关于」页点击「检查更新」，按顺序尝试更新源并校验签名后安装，安装后重启应用。
- 更新源顺序：国内镜像 `https://trae-updater.bczxy.xyz/latest.json` → `https://trae-updater.wanjiu.workers.dev/latest.json` → 本仓库发布页。镜像是 `deploy/` 下的 Cloudflare Worker，回源 GitHub Releases，并把安装包下载地址也改写为走镜像；`*.workers.dev` 在国内基本连不上，所以绑定了自定义域名。设置里的「自定义更新源」会排在最前。
- 发布产物：安装包（NSIS）与更新描述文件 `latest.json` 由 `npm run release` 一键生成并发布至本仓库的 Releases。每个正式 Release 都必须包含 `latest.json` 与 `setup.exe`（含 `.sig`），否则客户端自动更新会失效。

发布前需先关闭运行中的换号器，并同时提升 `src-tauri/tauri.conf.json`、`package.json`、`src-tauri/Cargo.toml` 三处版本号。`npm run release` 在构建前会检查：三处版本号一致、没有未提交的改动、当前提交已推送到远程 `main`，并把 Release 标签打在当前提交上。

## 开发与构建

环境要求：Node.js、Rust 工具链（MSVC）、Tauri CLI 依赖项。

```bash
npm install          # 安装前端依赖，并启用 .githooks
npm run dev          # 启动前端开发服务
npm run tauri dev    # 以开发模式启动完整应用
npm run build        # 类型检查 + 构建前端资源
npm run tauri build  # 构建发布版应用（NSIS 安装包）
npm run release      # 注入签名私钥并一键构建、生成 latest.json、发布
```

技术栈：

- 前端：React 19 + TypeScript + Vite + Tailwind CSS 4
- 后端：Rust + Tauri 2（含通知、更新、进程插件）
- 关键依赖：`rusqlite`、`p256`（ECDSA）、`aes`/`cbc`、`sha2`/`sha1`、`winreg`、`ureq`、`tungstenite`

### 目录结构

```
trae_switcher/
├─ src/                    前端源码
│  ├─ components/          通用组件（卡片、侧栏、标题栏、状态栏、对话框等）
│  ├─ pages/               页面（账号池、积分与诊断、会话迁移、日志、运行检查、设置、关于）
│  ├─ App.tsx              应用主逻辑与全局状态
│  └─ bridge.ts            前端到后端命令的桥接层
├─ src-tauri/              后端源码
│  ├─ src/commands.rs      Tauri 命令入口
│  ├─ src/core/            核心模块（切换、注入、shim、额度、资产、签到、日志等）
│  ├─ capabilities/        权限配置
│  └─ tauri.conf.json      应用与打包配置
├─ scripts/                构建、发布与 git hook 安装脚本
├─ deploy/                 更新镜像（Cloudflare Worker）
├─ .githooks/              仓库 git hook
└─ package.json
```

技术要点：

- 后端耗时命令统一以 `async` + `spawn_blocking` 执行，避免阻塞主线程导致界面卡顿。
- 无感换号优先采用 shim 扩展 + 触发文件方案，调试端口仅作备用通道。
- 调试端口按版本分离（国际版 9223、CN 版 9224），防止跨版本污染登录态。

## 数据与文件位置

所有数据仅存储在本机当前 Windows 用户目录下：

| 路径 | 说明 |
| --- | --- |
| `%APPDATA%\TraeIDE-Switcher\accounts.dpapi` | 账号库（DPAPI 加密，仅本机当前用户可解密） |
| `%APPDATA%\TraeIDE-Switcher\accounts.bak` | 上一版账号库备份 |
| `%APPDATA%\TraeIDE-Switcher\settings.json` | 应用设置 |
| `%APPDATA%\TraeIDE-Switcher\usage-history.json` | 额度采样历史 |
| `%APPDATA%\TraeIDE-Switcher\switch-history.json` | 切换历史时间线 |
| `%APPDATA%\TraeIDE-Switcher\instances\<账号>` | 多开实例的独立用户数据目录 |
| `%APPDATA%\TraeIDE-Switcher\logs\YYYYMMDD.log` | 运行日志 |

隐私说明：账号凭据与设备资产仅保存在本机，使用 Windows DPAPI 加密，不上传至任何服务器；应用仅在查询额度、签到、领取活动奖励等必要操作时直接访问 Trae 官方接口。

## 常见问题

**切换后停留在登录页 / 提示 TokenInvalid**
账号凭据不完整或已过期。请重新登录采集该账号入池，并确保账号凭据字段完整。

**无感换号不生效，提示未安装**
无感换号支持文件未安装。请以管理员身份运行本软件，先关闭 Trae，在「设置 → 无感换号通道」重新安装后重启 Trae。

**Trae 升级后无感换号失效**
Trae 升级会覆盖安装目录下的补丁文件，需重新安装无感换号支持并重启 Trae。

**出 20403 设备不匹配 / 设备绑定受限**
该账号的设备身份与当前设备不一致。设备身份随账号独立存储，请使用该账号入池时保存的设备资产进行切换，或重新登录采集。

**换号后看不到之前的对话**
按工作区显示：在原来聊天的那个文件夹里打开对话列表，而不是 Agent 首页。换号时本工具会自动把同一工作区的旧会话改挂到当前账号；目标工作区还没在新账号下打开过时，可在「会话迁移」页退出 Trae 后勾选迁移，或点「全部迁移」。

**提示「操作过于频繁，请稍候再试」**
这是 Trae 服务端返回的风控限流（错误码 4011，ABNORMAL_ACCOUNT_LIMIT），常见于短时间内连续换号。安装最新「无感换号支持」后，客户端会自动按 8s、16s… 线性退避重试本轮对话，服务端解除限制后自动续上；未安装补丁时需等待后手动重发。

**应用内「检查更新」报错**
请确认当前网络能访问 `trae-updater.bczxy.xyz` 或 GitHub 发布页。0.1.23 及更早的版本没有内置新镜像域名，可在「设置 → 自定义更新源」填入 `https://trae-updater.bczxy.xyz/latest.json` 后再检查更新。
